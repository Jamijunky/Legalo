# Legalo demo video (≤ 10 minutes)

Record 1080p. The story is **routing**, not features.

## 0:00–0:50 — Do not pitch RAG

“If we pitch multilingual RAG, we lose. Watch a sentence with no department in it.”

Type: **My scholarship has been pending for four months.**

Show the interpretation card: *pending application* as a hypothesis, alternatives (payment stuck / KYC / eligibility), confidence not 100%.

## 0:50–3:30 — Discriminators

Click **pending_application**, then **state** (not NSP).

Say: “If we had filed on rtionline.gov.in we would have wasted the fee. That is the bug.”

Fill name/address. Show an RTI for file notings — not an eligibility opinion.

## 3:30–5:00 — Same words, different pathway

**My scholarship was approved but the money has not come.** → `disbursement_failed`, RTI for the payment file / DBT.

**Am I eligible for a scholarship?** → refuse to invent eligibility; offer RTI for criteria the department already holds.

## 5:00–7:00 — Wrong-forum traps

Shop refund → consumer / e-Jagriti, **not** RTI.

Electricity + two-day notice → Model Tenancy ss.20–21, state law may differ.

## 7:00–9:00 — Provenance

`/sources`. RAG grounds the path already chosen. Dated official sources only.

## 9:00–10:00 — Generalises as data

Open `data/routing/pathways.json`. “A fourth domain is a new row. We did not boil India.”
